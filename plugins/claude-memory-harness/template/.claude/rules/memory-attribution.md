# Memory File Attribution

When updating any memory file (`memory-sessions.md`, `memory-decisions.md`, or any
future memory file), always include your agent identifier in the section heading.

**Format:** `## YYYY-MM-DD: Description [Agent Name]`

This allows the user to track which AI assistant (or human) made each entry, since
multiple agents may share this workspace.
